## Featured projects

- **[nepali-eval](https://github.com/iamnarace/nepali-eval)** (Python): Evaluation harness for Nepali-language AI output. Scores answers the way a Nepali reader would accept them (`१०` = `10`, `।` = `.`), keeps spelling variants as separate references, and supports human scoring alongside automatic metrics.
- **[nepali-data-commons](https://github.com/iamnarace/nepali-data-commons)** (Python): Contribution, review and export workflow for Nepali text data: checks Devanagari quality, flags personal data and duplicates, requires a second reviewer, publishes a dataset card, and logs takedowns.
- **[robotspec](https://github.com/iamnarace/robotspec)** (Python): Tests a `robots.txt` like code: RFC 9309 matching, a crawler access matrix (including AI crawlers) and policy checks that run in CI.
- **[devdesk](https://github.com/iamnarace/devdesk)** (TypeScript, React, Vite): Offline developer utility workbench: JSON, diff, Base64, URL, UUID and timestamps, with no external network requests.
- **[fairhour](https://github.com/iamnarace/fairhour)** (JavaScript, no dependencies): Plans a recurring meeting across time zones so nobody always takes the 6 am call, with daylight-saving-aware scoring and `.ics` export.
- **[paperflow](https://github.com/iamnarace/paperflow)** (TypeScript, React, pdf-lib): Merge, split, reorder and clean PDF metadata entirely in the browser; files never leave the device.

Also: [nepali-resource-audit](https://github.com/iamnarace/nepali-resource-audit) (overlap and licence audit for community dataset lists) and [penny-split](https://github.com/iamnarace/penny-split) (split an itemised receipt to the exact cent).

Most repositories here are recent and deliberately small. Each README states its status, how to run it and its known limitations.
